# АэроТех 74 — макеты сайта

Два варианта сайта компании по монтажу систем вентиляции и кондиционирования
в Челябинске. Оба статические (HTML + CSS + JS без сборки и зависимостей),
рассчитаны на частных и коммерческих клиентов.

| Вариант | Адрес | Для чего |
|---|---|---|
| Одностраничник | http://127.0.0.1:8712/ | быстрый запуск, весь оффер на одном экране |
| Многостраничник | http://127.0.0.1:8712/multi/ | SEO: отдельные страницы под услуги, цены, блог |

Доступ из локальной сети: `http://192.168.0.107:8712/` и `http://192.168.0.107:8712/multi/`.

## Как открыть

Сервер уже запущен. Перезапуск вручную:

```bash
cd "МАКС"
python3 -m http.server 8712 --bind 0.0.0.0
```

## Структура

```
index.html          — одностраничник (семантические секции с id)
styles.css          — стили, дизайн-токены в :root, адаптив
script.js           — интерактив без библиотек
multi/              — собранный многостраничник (15 страниц, sitemap, robots)
multi_src/          — генератор: build.py, content.py, extra.css
MULTIPAGE-SEO.md    — карта сайта, семантические кластеры, SEO-план
HOSTING.md          — выбор хостинга, смета, план запуска
GITHUB-PAGES.md     — бесплатный вариант на GitHub Pages и его ограничения
deploy/             — .htaccess и send.php для боевого сервера
.github/workflows/  — сборка и деплой на GitHub Pages
preview/            — скриншоты обоих макетов
shots/              — рабочие скриншоты
tools/              — скриншоты и проверки (Chrome DevTools Protocol, SEO-краулер)
```

## Сборка многостраничника

```bash
python3 multi_src/build.py          # пересобирает multi/
```

Контент и мета-теги — в `multi_src/content.py`, шаблоны — в `multi_src/build.py`,
дополнительные стили — в `multi_src/extra.css`.

## Деплой

Кратко: Timeweb «Optimo» → домен .ru → `BASE = ""` и `SITE = "https://домен"`
в `multi_src/content.py` → `python3 multi_src/build.py` → загрузить `multi/`
в `public_html` → скопировать `deploy/.htaccess` и `deploy/send.php` →
включить SSL → проверить формы.

Подробно, со сметой и чек-листом: [HOSTING.md](HOSTING.md).

Бесплатный вариант на GitHub Pages (и почему он не всегда подходит для боевого
сайта): [GITHUB-PAGES.md](GITHUB-PAGES.md).

## Блоки страницы

1. **Шапка** — логотип, навигация, телефон, CTA «Вызвать замерщика», мобильное меню.
2. **Первый экран** — оффер, преимущества, показатели, форма расчёта за 15 минут.
3. **Сегменты** — частным клиентам, коммерческим клиентам, бесплатный выезд.
4. **Услуги** — проектирование, монтаж, подбор и продажа оборудования,
   сервис, реконструкция и модернизация, автоматика и диспетчеризация.
5. **Проектирование** — состав проекта, сроки, что входит в документацию.
6. **Монтаж** — этапы, цифры, гарантии.
7. **Порядок работы** — 5 шагов от заявки до первого включения.
8. **Выполненные работы** — портфолио с фильтром по типу объекта.
9. **Оборудование** — бренды, категории, калькулятор подбора мощности.
10. **Сервисное обслуживание** — три тарифа (Базовый / Стандарт / Премиум).
11. **О компании** — преимущества и отзывы.
12. **FAQ** — частые вопросы (аккордеон).
13. **Контакты** — реквизиты, форма заявки, схема проезда, соцсети.
14. **Подвал** — навигация, контакты, мини-форма звонка, юридическая строка.

## Интерактив

- мобильное меню-бургер;
- фильтр портфолио по категориям;
- калькулятор мощности (площадь → кВт и м³/ч);
- маска телефона `+7 (___) ___-__-__`;
- валидация и состояние «Заявка отправлена» у трёх форм;
- аккордеон FAQ (открыт один пункт);
- анимация появления секций и счётчиков;
- плавающая кнопка звонка, скрывается в подвале.

## Адаптив

Проверено на ширинах 360, 390, 480, 640, 768, 820, 900, 1024, 1120, 1280, 1440, 1920 px —
горизонтального скролла нет, сетки перестраиваются 3 → 2 → 1 колонка,
навигация уходит в бургер с 980 px.

## Что заменить перед запуском

- телефоны, адреса, e-mail, ИНН, названия объектов и цифры — демонстрационные;
- цены в тарифах и калькуляторе — ориентировочные;
- отзывы и портфолио — примеры, нужны реальные фото объектов
  (сейчас вместо фото — SVG-схемы, чтобы макет работал без внешних файлов);
- карта — стилизованная заглушка, подключить Яндекс.Карты или 2ГИС;
- формы — сейчас имитация отправки, подключить CRM/почту и согласие
  на обработку персональных данных по 152-ФЗ;
- добавить страницы политики конфиденциальности и соглашения.
