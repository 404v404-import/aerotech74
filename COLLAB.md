# Совместная работа на этапе запуска

Пока сайт живёт на GitHub Pages — это тестовая площадка. Здесь описан процесс,
чтобы несколько человек могли править контент и дизайн, не мешая друг другу.

## Что где лежит

| Файл / папка | Что внутри | Кто правит |
|---|---|---|
| `multi_src/content.py` | тексты, цены, контакты, услуги, проекты, статьи | контент-менеджер |
| `multi_src/build.py` | шаблоны страниц, мета-теги, микроразметка | разработчик |
| `multi_src/extra.css` | стили внутренних страниц | дизайнер |
| `styles.css` | общие стили (одностраничник и многостраничник) | дизайнер |
| `multi/` | **сгенерированный сайт** | не редактировать вручную |
| `deploy/` | `.htaccess` и `send.php` для боевого хостинга | разработчик |
| `.github/workflows/pages.yml` | автосборка и публикация | разработчик |

Главное правило: правим исходники в `multi_src/`, а не готовые HTML в `multi/`.
После правок сайт пересобирается одной командой.

## Локальный запуск

Нужен Python 3.9+ (на macOS и Linux уже есть).

```bash
# из папки проекта
python3 multi_src/build.py

# поднять локальный сервер
python3 -m http.server 8712 --bind 127.0.0.1
```

Открыть: http://127.0.0.1:8712/multi/

Пересобрать после правок — снова `python3 multi_src/build.py`, сервер
перезапускать не нужно, достаточно обновить страницу.

## Как менять контент

Все тексты — обычные строки в `multi_src/content.py`.

**Контакты и реквизиты** — словарь `COMPANY`:

```python
COMPANY = {
    "phone": "+7 (351) 200-00-00",
    "email": "zakaz@aerotech74.ru",
    "address": "Челябинск, ул. Труда, 84, офис 312",
    ...
}
```

**Страница услуги** — блок в `SERVICES`. Важные поля:

- `title` и `desc` — для поиска, до 60 и 180 символов;
- `h1` и `lead` — заголовок и подзаголовок страницы;
- `sections` — список пар «заголовок → HTML-текст»;
- `prices` — таблица цен;
- `faq` — вопросы и ответы (попадут в микроразметку);
- `related` — слаги других услуг для блока «Другие услуги».

**Новая услуга:** скопировать блок, поменять `slug`, добавить его в список
`ORDER` — страница, меню, сайдбар и sitemap обновятся автоматически.

**Проекты и статьи:** списки `PROJECTS` и `POSTS`.

После правок:

```bash
python3 multi_src/build.py
```

## Как менять дизайн

- внутренние страницы — `multi_src/extra.css`;
- общие блоки (шапка, футер, кнопки, карточки) — `styles.css`;
- после правок CSS пересобрать сайт, файл `multi/assets/style.css` обновится сам.

## Git-процесс

```bash
git checkout -b content/novye-ceny
# правим content.py
python3 multi_src/build.py
git add -A
git commit -m "Обновил цены на монтаж"
git push -u origin content/novye-ceny
```

Дальше — Pull Request в `main`. После мержа GitHub Actions сам пересоберёт и
опубликует сайт. Прямые пуши в `main` лучше закрыть: `Settings → Branches →
Add branch protection rule → Require a pull request before merging`.

Проверить перед PR:

```bash
node tools/check_multi.mjs http://127.0.0.1:8712
python3 tools/seo_check.py
```

Скрипты проверяют ссылки, `title`/`description`/`H1`, микроразметку и
горизонтальный скролл.

## Что важно знать про тестовую площадку

- сайт закрыт от индексации (`noindex` и `Disallow` в `robots.txt`) — это
  специально, чтобы тестовый адрес не конкурировал с будущим доменом;
- формы пока имитируют отправку: реальный обработчик `deploy/send.php`
  включается на боевом хостинге;
- телефоны, цены, отзывы и кейсы — демонстрационные, перед запуском заменяются.

## Переезд на боевой домен

1. Купить хостинг и домен ([HOSTING.md](HOSTING.md)).
2. В `Settings → Secrets and variables → Actions → Variables` добавить
   `CUSTOM_DOMAIN = aerotech74.ru`.
3. В `pages.yml` убрать строку `echo "NOINDEX=1"` (или перенести деплой на
   хостинг).
4. Загрузить `multi/` на хостинг, скопировать `deploy/.htaccess` и
   `deploy/send.php`.
5. Включить SSL, проверить формы, отправить `sitemap.xml` в вебмастера.

## Доступы

- владелец репозитория добавляет участников: `Settings → Collaborators → Add people`
  с ролью **Write**;
- дизайнеру и контент-менеджеру достаточно Write и защиты `main` через PR;
- секреты (пароли, токены) в репозиторий не коммитим — только через
  `Settings → Secrets and variables`.
